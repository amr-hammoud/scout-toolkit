# Scout Toolkit

An Arabic Morse code tool for scouts. Live demo: [scout-toolkit.amrhammoud.com](https://scout-toolkit.amrhammoud.com).

## Run it

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run build
npx wrangler deploy
```

## Stack

- React and TypeScript
- Vite
- Cloudflare Workers static assets
